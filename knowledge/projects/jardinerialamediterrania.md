# Jardinería La Mediterrània

## Qué es

Web de Jardinería La Mediterrània, un servicio de jardinería con presencia en Sitges, Vilafranca, Ribes, Cunit y alrededores. El propio sitio se presenta como «tus jardineros» en la zona y apela a la confianza para cuidar el jardín «con el mismo cariño y dedicación que hemos heredado generación tras generación».

## Tecnología

Astro.js, Tailwind CSS y Playwright.
