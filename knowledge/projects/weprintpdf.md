# WePrintPDF

## Qué es

Diseños imprimibles personalizables: calendarios, agendas, listas, calendarios perpetuos y otros imprimibles. La web funciona como landing para presentar los diseños y permite subir imágenes para personalizarlos. El nombre interno del proyecto es papira.

## Tecnología

SvelteKit.
